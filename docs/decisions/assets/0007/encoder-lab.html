T-140 編碼器實驗頁（WebCodecs 對照 WebRTC）

  1. 將 HTML 和四個 encoder-lab JS 檔放在同一資料夾，用桌面 Chrome 或 Edge 雙擊開啟。頁面會從 cdn.jsdelivr.net 載入 mediabunny 1.65.2。
  2. 如需 WebRTC dump，先另外開啟 chrome://webrtc-internals。回到本頁選一支本機影片（建議 4K 或 1080P、至少 90 秒），按「開始」。期間請留在本分頁。
  3. WebRTC 對照需要麥克風或鏡頭權限，才能讀取編碼器資訊。權限串流只維持擷取狀態，不會加入測試連線。兩種權限都無法取得時，JSON 會逐項記錄跳過原因。
  4. 手動存 dump 時，在 WebRTC 組仍在執行時從另一個視窗匯出。跑完後按「複製 JSON」。
