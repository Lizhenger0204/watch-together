T-140 編碼器實驗頁（WebCodecs 對照 WebRTC）

  1. 用桌面 Chrome 或 Edge 直接開這個檔案（雙擊即可，不用安裝）。需要網路：會從 cdn.jsdelivr.net 載入拆檔套件 mediabunny 1.65.2。
  2. 選一支本機影片（建議 4K 或 1080P、至少 90 秒），按「開始」。全程約 4～6 分鐘，期間不要切走分頁。
  3. 若跳出麥克風或鏡頭權限，請按「允許」：Chrome 只有在取得權限後，才會回報 WebRTC 用的是哪個編碼器。
  4. 跑完後按「複製 JSON」，貼回給 Claude。頁面先不要關，可到 chrome://webrtc-internals 按「Create dump」另存一份。
